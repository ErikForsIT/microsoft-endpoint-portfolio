# Portfoliodokument

**[Öppna portfolion som PDF](Erik-Fors-Microsoft-Endpoint-Portfolio.pdf)**

Den svenska portfolion omfattar **16 sidor och sex projekt** inom Microsoft Intune och Windowsadministration. Den innehåller en projektöversikt, konfigurationsval, skärmbilder och verifierade resultat.

På sidan 11 visar inloggningsloggen sammanlagd Conditional Access-status för OfficeHome. Policyns individuella utfall och ett försök med nekad åtkomst är inte dokumenterade där. På sidan 14 visar den lokala kontrollen tre aktiva antivirusskydd. Beteendeövervakningen behöver läsas av separat.
