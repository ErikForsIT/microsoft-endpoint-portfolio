# Portfoliodokument

**[Öppna portfolion som PDF](Erik-Fors-Microsoft-Endpoint-Portfolio.pdf)**

Den svenska portfolion omfattar **16 sidor och sex projekt** inom Microsoft Intune och Windowsadministration. Den innehåller en projektöversikt, konfigurationsval, skärmbilder och verifierade resultat.

Versionen är uppdaterad i september 2026 och motsvarar den genomarbetade Word-portfolion. PDF-formatet bevarar layout, bildplacering och typsnitt när dokumentet delas.

För källkod och projektspecifika detaljer finns [projektöversikten på startsidan](../README.md).
